# Video Compilation Configuration File
# Run: ./create_compilation.py
# Output: compilation.mp4 (source resolution + HDR/SDR; re-encoded)
# Also WhatsApp: ./create_compilation.py --whatsapp
# Output: compilation.mp4 + compilation_Whatsapp.mp4
# Custom config/name: ./create_compilation.py video_config.txt -o highlights.mp4
# WhatsApp from existing file: ./create_compilation.py -o highlights.mp4 --whatsapp-only
# WhatsApp size target: ./create_compilation.py --whatsapp --whatsapp-max-mb 50
# Help: ./create_compilation.py --help
#
# Format for video clips: filename | start_time | end_time | [text_overlay] | [speed] | [arrow] | [waveform] | [noaudio]
# Format for black screens: BLACK | duration | text | [audio_file] | [audio_start] (default: middle of the audio)
#   With audio_start, audio plays from that point and anything after duration seconds is cut from the end
# Format for still images: IMAGE | filename | duration | [text] (stretched to the video resolution)
# 
# Times: Use seconds (26), mm:ss (1:12), or hh:mm:ss (1:12:30). Decimals supported (26.23)
# Optional fields can be in any order: text_overlay, speed, arrow, waveform, noaudio
# Text overlay: Use \n for a new line. Example: First line\nSecond line
# Speed: 1=normal, 0.5=half speed (slow motion), 2=double speed, -1=reverse, -0.5=reverse slow motion
#   0=freeze: show the frame at start_time for (end_time - start_time) seconds, silent
#   Slow motion (speed below 1) is always muted
# Arrow: "arrow" keyword followed by arrow parameters
#   Use "arrow" alone for default (right), or "arrow 270" for degrees, or "arrow 45:800:600" for custom position
#   Degrees: 0=right, 45=down-right, 90=down, 135=down-left, 180=left, 225=up-left, 270=up, 315=up-right
# Waveform: "waveform" keyword to show audio amplitude visualization
# NoAudio: "noaudio" keyword to mute the clip (replace audio with silence)
#
# Output resolution, frame rate and HDR/SDR are taken from the first video clip;
# clips with a different size are scaled and padded (black bars) to match.
# FPS rounded to whole number, limited to 24-60. Need at least one video.
# No source audio = silence. IMAGE = silent. BLACK without audio = silent.
# Short BLACK audio = silence at end. Missing video/image/audio = error + stop.
# All source paths checked before encoding. Failed clip = error + stop.
# WhatsApp = SDR, H.264, max 30fps, 7000kbps; size target defaults to 185 MB.
#
# Example entries:
# Normal playback:
# 20251108_090053.mp4 | 3 | 5 | MÅL!!! | 1
#
# Replay (0.1 speed for frame-by-frame):
# 20251108_090053.mp4 | 3 | 5 | Replay | 0.1
#
# Slow motion:
# 20251108_090053.mp4 | 3 | 5 | Slow! | 0.5
#
# With waveform:
# 20251108_090053.mp4 | 3 | 5 | | waveform
#
# With arrow (degrees):
# 20251108_090053.mp4 | 3 | 5 | | arrow 270
#
# With arrow (custom position):
# 20251108_090053.mp4 | 3 | 5 | | arrow 45:800:600
#
# Reverse:
# 20251108_090053.mp4 | 3 | 5 | Reverse | -1
#
# Reverse slow motion:
# 20251108_090053.mp4 | 3 | 5 | Reverse slow | -0.5
#
# Freeze frame (still at 3s, held for 2s):
# 20251108_090053.mp4 | 3 | 5 | Look here! | 0
#
# Black screen with text:
# BLACK | 1.5 | Goal Highlights
#
# Black screen with text and sound:
# BLACK | 3 | A few moments later | a_few_moments_later.mp3
# BLACK | 3 | A few moments later | a_few_moments_later.mp3 | 0
# BLACK | 3 | A few moments later | a_few_moments_later.mp3 | 1.5
#
# Still image for 5 seconds:
# IMAGE | screenshot.png | 5 |
#

# 20251108_090053.mp4 | 3 | 5 | Nice goal! | 1 | noaudio
#
# Combined features:
